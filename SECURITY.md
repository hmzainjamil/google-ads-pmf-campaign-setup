# Security and publication notes

## Scope

This note covers sensitive material found in the repository's campaign checklist and import workbook. It is not a security or legal audit.

## Removed material

The former checklist and workbook contained account-specific identifiers and campaign content for a financial product, including financial return claims, budget and targeting plans, contact details, and compliance language. The workbook is removed from this branch. The checklist is replaced with a status record. These changes do not erase earlier Git history, forks, cached copies, or local downloads.

The maintainer should review the prior public material, assess notification or remediation needs with the account owner, and revoke or rotate any credential if one was exposed. No credential was confirmed in the reviewed files.

## Use boundary

Do not upload or publish campaign material based on this repository without account-owner authorization and qualified legal/compliance review. Repository text does not establish securities-law compliance, accreditation verification, Google Ads approval, or expected returns.

## Evidence limit

No live account, deployment, legal review, or campaign performance verification was performed.
